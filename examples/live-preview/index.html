Preview · Live example

Some work is better explored than downloaded.

Preview is how I publish and share interactive reports, prototypes and experiments without turning them into static attachments. This page is itself a real Preview document.

Two sides of one share

Switch perspective to see what Preview keeps simple for the person opening the work and for the person publishing it.

Recipient view

The experience stays intact.

A deliberate link opens the interactive work directly in the browser, inside Preview’s isolated viewer.

  1. Open one clear link

    No account, content directory or public profile stands between the recipient and the shared work.

  2. Explore the real HTML

    Layout, controls and small interactions remain available instead of being flattened into screenshots or slides.

  3. Use the format that helps

    When a PDF companion exists, it remains an optional download rather than replacing the browser experience.

Owner view

Each share stays under control.

The same published work can have separate labelled links, each with its own boundary and stable destination.

  1. Publish authored HTML

    Upload a single HTML file or a small package through the owner interface or the MCP publishing workflow.

  2. Create deliberate links

    Set an expiry, revoke access when needed or keep a link active for a deliberately public example like this one.

  3. Update without another URL

    Replace the content behind the stable link while preserving its purpose and aggregate history.

Deliberate boundaries

A small, inspectable, single-owner project.

Preview runs on a Cloudflare Worker and D1 across separate application and content origins. It is not hosted SaaS, a multi-user platform or a public directory.

Aggregate signals are useful context, not reader identity or proof that someone read the work. Owner-authenticated activity is excluded from recipient measurement.
This deliberately public example contains no client material or production analytics. Its source lives in the Preview repository and is updated through the same publishing lifecycle it describes.
