# Support

Preview is maintained as Carlo Caprini's personal utility and a public
reference implementation. It is not a supported hosted product.

Public GitHub issues may be used for reproducible bugs, focused documentation
problems, or small proposals that fit the existing product boundaries. Review,
answers, fixes, releases, and pull-request merges are all best-effort. There is
no SLA, compatibility guarantee, guaranteed roadmap, setup service, or private
support channel for forks.

Before opening an issue:

1. Read the README and relevant document under `docs/`.
2. Reproduce the problem from a clean `npm ci` install.
3. Run the documented checks and record only non-sensitive output.
4. Remove credentials, live share links, customer data, and private logs.

Ask Cloudflare account, billing, quota, or platform questions through
Cloudflare's own documentation and support channels. Ask dependency-specific
questions upstream when the behavior is not Preview-specific.

Security vulnerabilities do not belong in public issues. Follow
[`SECURITY.md`](SECURITY.md).
